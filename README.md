# Voxlive

Lector de chat en vivo para **Twitch** y **TikTok**. Windows 11 x64.

## Programas

| Archivo | Qué hace |
|---|---|
| `Voxlive.exe` | Completo: Twitch + TikTok |
| `Voxlive-Twitch.exe` | Solo Twitch |
| `Voxlive-TikTok.exe` | Solo TikTok |

Todos van dentro de `Voxlive.zip`.

## Cómo usarlo

1. Descarga `Voxlive.zip`.
2. Extrae el zip.
3. Doble clic en el `.exe` que quieras.
4. Si Windows dice “Windows protegió tu PC”: **Más información → Ejecutar de todas formas**.
5. Escribe tu canal de Twitch (sin `#`) y/o tu usuario de TikTok (sin `@`).
6. Pulsa **Conectar**. El chat se lee en voz alta.
7. No pide contraseña.
8. TikTok solo envía chat si tu LIVE está abierto.

## Subir el zip a este repo

1. En este repositorio pulsa **Add file → Upload files**.
2. Arrastra `Voxlive.zip`.
3. **Commit changes**.
4. Luego puedes crear un **Release** (Releases → Draft a new release) y adjuntar el mismo zip para un botón de descarga grande.
