# Chat handoff

New Grok / new thread: read this file, then the **latest** file in `chats/`.
Do not restart the product. Do not revive Stripe live. Do not rewrite `app.js` unless the owner pastes a concrete studio bug.

This folder is the compiled memory of owner chats. One file per session. Keep files short. No secrets, no `ADMIN_SECRET`, no Ko-fi verification tokens, no OAuth client secrets, no Euler keys.

## How to start a new chat

Paste this:

```
Continue VoxStream from YuiCoder/VoxStream.
Read CHATS.md and the latest file in chats/ first.
Do not restart. Do not edit app.js unless I paste a bug.
```

Then work from **Next** in the latest log.

## How to close a chat (owner or bot)

Before the thread dies, append or add `chats/YYYY-MM-DD-short-slug.md` with:

- Date
- What shipped
- What the owner confirmed in the UI
- What is still open
- Files touched
- Explicit do-nots from that session

One session = one file. Update the index table below.
