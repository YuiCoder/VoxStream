# Contribuir a VoxStream

Gracias por echar una mano. Este repo es una web en GitHub Pages. No hay exe. No hay servidor de pagos.

Thanks for helping. This repo is a GitHub Pages site. No exe. No payment server.

## Español

### Qué sí puedes tocar
- `README.md` y `CONTRIBUTING.md`
- Copy de `index.html` (textos de la landing)
- Copy de `studio.html` (etiquetas, hints, checklist)
- Issues

Haz un fork y abre un pull request. No subas directo a `main`.

### Qué no toques
- `app.js` (la lógica del estudio)
- Secretos, tokens, claves API
- Settings del repo (Pages, secrets, actions)
- `main` sin un PR

No pegues claves de Euler, TikTok o ElevenLabs.
No añadas Stripe, login ni un `.exe`.

### Cómo probar
1. Abre https://yuicoder.github.io/VoxStream/ o tu fork en Pages.
2. Pulsa **Probar voz**.
3. Conecta un canal de Twitch en directo, o deja **Ensayo** encendido.

## English

### Safe to edit
- `README.md` and `CONTRIBUTING.md`
- Copy in `index.html`
- Copy in `studio.html`
- Issues

Fork and open a pull request. Do not push to `main`.

### Do not touch
- `app.js`
- Secrets, tokens, API keys
- Repo Settings (Pages, secrets, actions)
- `main` without a PR

Do not paste Euler, TikTok, or ElevenLabs keys.
Do not add Stripe, login, or an `.exe`.

### How to test
1. Open the Pages site.
2. Click **Probar voz**.
3. Connect a live Twitch channel, or leave **Ensayo** on.
